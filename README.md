# 拼多多自动发货助手

**[点击下载安装包，双击后按提示安装即可使用](https://github.com/getinfo8888-sys/pdd-auto-delivery-assistant/releases/download/v0.3.14/PDD-Auto-Delivery-Assistant-Setup-0.3.14-x64.exe)**

适用 Windows 10 / 11 的 64 位电脑。无需懂代码，不用安装 Node.js，也不用下载源码。

Windows 本地桌面工具，通过商家本人登录的拼多多官方商家页面，提供智能答复、商品名称 / SKU 匹配发货、确认虚拟发货和自动退款。

## 怎么下载安装和使用

1. **[点这里下载安装包](https://github.com/getinfo8888-sys/pdd-auto-delivery-assistant/releases/download/v0.3.14/PDD-Auto-Delivery-Assistant-Setup-0.3.14-x64.exe)**，保存到电脑。
2. 双击下载的文件，按提示点“下一步”→“安装”→“完成”。以后双击桌面的“拼多多自动发货助手”就能打开。
3. 打开软件，登录自己的拼多多商家账号，设置要回复、发货的内容，再点“开始监听”。

需要详细设置步骤，查看 [使用说明](docs/使用说明.md)。首次使用需要先登录店铺并配置自己的内容。

每次正式更新都会发布新版安装包，可在 [所有版本与便携版](https://github.com/getinfo8888-sys/pdd-auto-delivery-assistant/releases) 下载；标有 Portable 的文件是免安装版。

## 功能

- 智能答复：欢迎语、关键词、精确 / 通配符 / 表达式匹配及未匹配默认答复。
- 自动发货：根据商品名称或 SKU 包含的关键词选择内容，支持未匹配默认发货、统一尾缀、独立纯链接和图片 / 二维码。
- 成功核验：发送取得平台回执后再确认发货；失败重试，结果不明先核实，保留处理记录。
- 自动退款：单独开启后，处理平台标记为需商家同意的退款申请。
- 持续运行：启动补答、待发货补单、断网重连及页面刷新、关闭到托盘、已识别的客服功能引导清理。
- 异常提醒：电脑右下角弹窗默认开启，可配置微信或短信；持续恢复失败后提醒，同一故障不反复通知。

首次运行没有预置的商品或答复规则。规则、图片元数据和记录保存在本机；图片通过当前登录店铺的官方客服组件上传到拼多多。登录与安全验证需由商家本人完成。

## 本地开发

源码结构和验证方式见 [开发说明](docs/开发说明.md)，仓库同步和版本发布见 [GitHub 发布说明](docs/GitHub发布说明.md)。

需要 Windows x64 和 Node.js 24 或更新版本。

```powershell
npm ci
npm start
npm test
npm run dist
```

安装包位于 `dist/拼多多自动发货助手-版本号-安装包-x64.exe`。需要便携版本时执行 `npm run dist:portable`，输出为 `dist/拼多多自动发货助手-版本号-win-x64.exe`。

本项目为独立开发的商家工具。接入依赖官方网页当前提供的组件和接口，页面变更后可能需要适配。接口可达与页面显示状态分别检测，业务成功以平台回执为准。

本地数据目录沿用 `%APPDATA%/LinkDeliveryWorkbench`，便于旧版升级保留规则和登录会话。安装目录与数据目录相互独立，卸载默认保留本地数据。源码与分发包不包含开发者的店铺配置、登录数据、客户记录或第三方原程序。
