# 拼多多自动发货助手

Windows 本地桌面工具，通过商家本人登录的拼多多官方商家页面，提供智能答复、商品名称 / SKU 匹配发货、确认虚拟发货和自动退款。

## 功能

- 智能答复：欢迎语、关键词、精确 / 通配符 / 表达式匹配及未匹配默认答复。
- 自动发货：根据商品名称或 SKU 包含的关键词选择内容，支持未匹配默认发货、统一尾缀、独立纯链接和图片 / 二维码。
- 成功核验：发送取得平台回执后再确认发货；失败重试，结果不明先核实，保留处理记录。
- 自动退款：单独开启后，处理平台标记为需商家同意的退款申请。
- 持续运行：启动补答、待发货补单、断网重连及页面刷新、关闭到托盘、已识别的客服功能引导清理。

首次运行没有预置的商品或答复规则。规则、图片元数据和记录保存在本机；图片通过当前登录店铺的官方客服组件上传到拼多多。登录与安全验证需由商家本人完成。

## 使用

普通使用者进入本仓库右侧的 **Releases**，下载文件名带 **Setup** 的安装包（PDD-Auto-Delivery-Assistant-Setup-版本号-x64.exe），双击后按向导安装即可。安装向导使用简体中文，可选择安装目录，默认安装给当前用户，并创建桌面和开始菜单快捷方式。安装完成后可直接运行。

无需安装 Node.js、运行命令或解压源码。源码 ZIP 供开发者修改和构建程序使用；日常使用请选择安装包。

1. 启动程序，在“店铺工作台”登录自己的商家账号。
2. 在“发货内容”填写匹配关键词和要发送的内容，在“智能答复”配置欢迎语、关键词和默认答复。
3. 用本地预览核对匹配结果，再在“助手设置”开启需要的功能。
4. 开始监听，或开启“打开软件自动监听”。发送、发货及退款的实际结果见运行记录。

详细说明见 [使用说明](docs/使用说明.md)，源码结构和验证方式见 [开发说明](docs/开发说明.md)。维护者可阅读 [GitHub 同步与发布说明](docs/GitHub发布说明.md)。

## 本地开发

需要 Windows x64 和 Node.js 24 或更新版本。

```powershell
npm ci
npm start
npm test
npm run dist
```

安装包位于 `dist/拼多多自动发货助手-版本号-安装包-x64.exe`。需要便携版本时执行 `npm run dist:portable`，输出为 `dist/拼多多自动发货助手-版本号-win-x64.exe`。

本项目为独立开发的商家工具。接入依赖官方网页当前提供的组件和接口，页面变更后可能需要适配。接口可达与页面显示状态分别检测，业务成功以平台回执为准。

本地数据目录沿用 `%APPDATA%/LinkDeliveryWorkbench`，便于旧版升级保留规则和登录会话。安装目录与数据目录相互独立，卸载默认保留本地数据。源码与分发包不包含开发者的店铺配置、登录数据、客户记录或第三方原程序。
